# catan-starfarers — 宇宙を開拓するボードゲームの試作

母船を振って速さを決め、植民船と交易船で星々へ。植民地を広げ15点を目指す3〜4人のボードゲームの試作。CPUと遊べます。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan-starfarers/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

サイコロで産出 → 交易・建設 → 母船を振って飛行、の順に手番を進めます。黒が出たら遭遇。植民船で植民地を、交易船で前哨基地に交易所を建て、点を 15 集めたら勝ちです。画面右上の「遊び方」から 30 秒で読める説明を開けます。

## 市販のボードゲームとの違い

遊びの骨格は市販のボードゲーム（宇宙開拓を題材にした拡張版）に合わせていますが、資料が無い・画面向けに変えた部分があります。

| 点 | どうしたか | 理由 |
|---|---|---|
| 盤の並び | 決まった並びは使わず、ランダムな配置（星1つ＝手前8か所、星2つ＝奥7か所）。格子の形は自前 | 座標が資料に無い。遊びは変わらない |
| 準備 | 上級者向けの4周の進め方だけ | 同上 |
| 先手を決める | ランダムに選ぶ | 結果は同じで操作が1つ減る |
| 遭遇カード | 公式の「型」（数を選ぶ／はい・いいえ、戦い、速さ比べ）だけを使った、自前の20枚 | 文面が資料に無い。写すと著作権の問題になる |
| 海賊役・比べる相手 | 右隣に統一 | 自前のカードなので決めた |
| 予備の山の引き忘れ | 自動で引く | 画面なので忘れようがない |
| 相手との交易 | 手番の人が出し、相手が受けるか断る1対1の形 | 1台の画面で回すため |

これ以外のルール（資源・建設のコスト、速さ・戦闘力の計算、得点など）は市販のボードゲームの数値に合わせています。

## 自前の遭遇（20枚）

遭遇カードは文面も数値も自分で考えた自前のもの。公式の「結果の型」（数を選ぶ・はい/いいえ・戦い・速さ比べ）だけを借りています。

- **商人の船・旅人**: 資源を何枚贈るか選び、渡した量に応じて見返り（資源・宇宙ジャンプ・名声）が変わる
- **海賊の要求・海賊の待ち伏せ**: 資源を渡すか、戦うか。勝てば名声やほかの船の資源、負けると名声やアップグレードを失う
- **ワームホール**: 速さ比べに勝てば宇宙ジャンプ、負けると船が動けなくなる
- **遭難船・無人の補給基地・迷子の交易船**: 助ける／調べる／引き取るを選び、名声や資源、アップグレードが絡む
- **摩耗**: 全員が共通で影響を受け、アップグレードの一番多い種類を1つ失う

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
